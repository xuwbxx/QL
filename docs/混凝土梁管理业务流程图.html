source → calculation 为"导入原件 → 计算结果"两段式；ascast_coordinate / ascast_measure 由梁段填报经算法派生，三者属同一条计算链，作废必须同事务整体作废。

三、核心业务规则

  • 填报顺序锁：ConcreteBeamWorkflowRules.DescribeSegmentFill —— 不跳段，新增仅允许紧邻下一节（m = 已填最大段 + 1），更新仅允许最后一节；违反时返回 SkipSegmentMessage / LockedSegmentMessage。
  • 上游锁定：IsUpstreamLocked —— 一旦存在实测填报（biz_concrete_beam_segment 有效行），项目参数、设计坐标、预拱度全部只读。
  • 配置变更作废：ShouldInvalidateAsCastAfterConfigChange —— A/B/C/H 任一变化即作废既往浇筑坐标（首次保存除外）。
  • 预拱度联动：ShouldClearCamberAfterDesignConfirmation —— 标高不含预拱度且旧预拱度不可复用时，确认设计坐标须清独立预拱度。
  • 导入防越权：ConcreteBeamImportPreviewStore —— 预览 Token 校验账号 / 浇筑组 / 类型，30 分钟滑动过期。
  • 数据权限：GetAllowedProjectIds() —— admin 角色全量，否则按 biz_project_user 授权过滤。
