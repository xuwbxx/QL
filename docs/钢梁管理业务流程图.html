三、核心业务规则

  • 测点编号约束：必填、≤50 位可见半角字符、禁中文/空格、不得以 = + - @ 开头（HasValidPointCode）、Excel 内查重且同一项目内跨梁唯一。
  • 数值精度：坐标/预拱度最多 4 位小数，入库统一 Math.Round(...,4)；权值范围 0~1。
  • 实测完整性：ValidateMeasuredSegmentCompleteness —— 某梁段被触及则其所有理论点位必须整段齐全。
  • 批次递进：新导入 PushCount 只能是 max 或 max+1（SteelPushCountOutOfRange）；仅最新批次可编辑（SteelPushCountNotEditable）。
  • 覆盖确认：同批次同时间覆盖需 confirmOverwrite=true，事务内二次校验；旧批次记 ReplacedByBatchID 形成覆盖链。
  • 理论数据锁定：一旦存在任何实测批次，理论数据锁定（SteelTheoryLockedForEdit / LockedForImport）。
  • 完整点集隔离：监控联系单计算强调「不能跨批次混用」——实测优先、推算补齐（LoadLatestCompleteSetAsync）。
  • 数据权限：EnsureGirderAccess → 验证 BeamType=0 → EnsureProjectAccess；GetAllowedProjectIds admin 全量，否则按 biz_project_user 授权；JWT 未登录抛 Unauthorized。
  • 留痕：错误/成功导入的原始 Excel 均落盘（SaveOriginal，目录取配置 SteelBeam:FileRoot，默认 App_Data）。
